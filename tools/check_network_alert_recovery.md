# 网络告警恢复回归

运行 `python3 tools/check_network_alert_recovery.py`（需要 JDK 17，首次 Android 构建后使用本机 Kotlin 编译缓存）。脚本提取生产代码中的网络告警发送/清除方法，在模拟通知管理器上运行。

覆盖：成功后清除网络告警、连续失败保留告警、再次失败重新提醒、进程重启清理遗留通知、保留风控和运行通知、撤销失败可重试、正常请求不重复调用通知服务。另检查成功 RPC 分支与网络熔断告警入口接线。

真实手机仍需验证通知投递和任务运行。本修复不关闭离线熔断、不自动解除风控、不修改网络重试策略。旧版本使用通用告警编号 98 的历史通知不自动按标题猜测删除；新网络告警使用 97。
